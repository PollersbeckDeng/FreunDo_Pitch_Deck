# FreunDo Investor Website

Premium, mobile-friendly static investor website rebuilt from the supplied FreunDo pitch deck.

## Included
- Responsive investor narrative with interactive chapter navigation
- Market Adoption calculator
- Interactive technology panels
- Full 20-slide deck viewer + original PowerPoint download
- Official FreunDo logo supplied by the founder
- Founder profile photography in the Team chapter (sourced from the supplied pitch deck)
- Mobile navigation and swipe-friendly deck browsing

## Run locally
Open `index.html` in a browser. For best results, serve the folder using any simple local static server.

## Hosting
This is a plain HTML/CSS/JavaScript site and requires no paid service. It can be hosted on any static host or your existing web server.
